---

## 🌟 Key Features & Engineering Highlights

### 1. 🎨 Liquid Glassmorphism Design System
- Built with custom translucent cards (`backdrop-blur-xl`, `bg-white/78`, subtle light borders) and ambient liquid gradient orbs.
- Strict **`rounded-full`** pill component architecture across all interactive buttons, category chips, and badges as per organization design guidelines.
- Responsive layout with generous vertical rhythm and isolated containers, eliminating layout drift across viewports.

### 2. 🔊 Interactive VoiceCraft Sound Lab
- **Real-Time Audio Frequency Equalizer**: Dynamic animated soundwave visualizer simulating speech frequencies across 100Hz to 8kHz.
- **Studio-Quality Spoken Voice Samples**: High-fidelity speech demonstrations featuring a natural, articulate Indian female voice representing **Trainer Jothi (Founder & Master Coach)**:
  - *IELTS Band 8.5 Speech: The Greatness of India*
  - *Welcome to VoiceCraft: Our Academy & Services*
  - *Eloquence Keynote: Stage Presence & Leadership*
  - *Bonjour French Immersion: Global Horizons*
- Interactive audio player controls with progress scrubbing, real-time timer, and synced speech transcripts.

### 3. 🧭 60-Second Speaking Diagnostic Quiz
- Interactive 3-step assessment identifying students' core communication barriers (hesitation, mother-tongue influence, stage fear, or grammar).
- Delivers an instant personalized coaching roadmap and recommended program module.

### 4. 📚 The 4 Flagship Program Modules
- Comprehensive curriculum showcase for:
  1. **IELTS & PTE with VoiceCraft** (Band 7.5+ strategies & 1-on-1 mock interviews)
  2. **Bonjour by VoiceCraft** (French CEFR A1–B2 & Canada PR TEF preparation)
  3. **Eloquence by VoiceCraft** (Public speaking, debate, and executive presence)
  4. **EngLingo by VoiceCraft** (Workplace English, accent neutralization, and fluency)

### 5. 🚀 High-Converting Lead Generation & Local SEO
- Seamless contact form wired to **Web3Forms** with real-time feedback states.
- 1-click WhatsApp quick connection (`+91 99199 11027`).
- Embedded **LocalBusiness Schema.org JSON-LD** structured data for Bengaluru local search rankings.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### 1. Clone the repository
```bash
git clone https://github.com/LoneRanger-dev/voicecraft-academy.git
cd voicecraft-academy
```

### 2. Install dependencies & run frontend
```bash
cd voicecraft-frontend
npm install
npm run dev
```

The site will be live at `http://localhost:5173`.

### 3. Build for production
```bash
npm run build
```
Generates production-optimized static assets in the `dist/` directory.
